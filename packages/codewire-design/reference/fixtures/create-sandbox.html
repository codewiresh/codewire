Resources and lifetime

CPU uses millicores (1000 = 1 vCPU). Memory uses MiB; disk uses GiB. These choices are submitted even when this section is closed.

This schedules automatic deletion, including workspace files—not an idle timeout. Empty, 0, or infinity uses the saved configuration's default and may still schedule deletion. Stop and activity do not cancel the deadline; setup and Start reschedule it. The Sandbox lifecycle assigns the actual deletion deadline.

Ports

HTTPS previews forward HTTP requests to the internal port your application listens on. There is no separate external port number or arbitrary TCP forwarding.

Provisional URL pattern: https://{label}-{sandbox-id-prefix}-example.preview.example.test. The five-character Sandbox ID prefix is assigned after creation; this is not an assigned URL.

Creator previews require the creator to sign in. Organization previews require membership and access to this Sandbox. Public previews are available to anyone with the URL; confidential policy may still require sign-in.

Leave this list empty to omit HTTPS preview routing, or remove an entry later in Ports. This does not block every other form of network access.
