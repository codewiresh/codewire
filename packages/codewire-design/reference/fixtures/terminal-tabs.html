Stop Fixture Sandbox?

Running processes and terminal sessions will end. Workspace files are kept so you can start the Sandbox again. Stopping does not cancel automatic deletion. Starting again reschedules the deadline when a lifetime is configured. Protected Sandboxes are exempt from automatic deletion.
