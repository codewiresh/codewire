Secrets

Application secrets owned by your account, independent of organization selection.

Return to Create Sandbox

Storing a secret does not attach it to a Sandbox. Selecting your personal secret source makes its values available to that workload under their original names. Provider credentials belong in Credentials.

Application secrets

Only key names and update times are readable. Stored values are never returned.

  • DATABASE_URL

    Updated 2 hours ago

    Replace DATABASE_URL

    The new value replaces DATABASE_URL in your personal application secrets. Future use of this source uses the replacement; already-running processes may retain an earlier value.

    Write-only. Up to 64 KiB of UTF-8 text. The value is not shown after saving.

    Rename DATABASE_URL

    This changes the variable name in your personal secret source. Workloads expecting DATABASE_URL may need updating.

    Use letters, numbers or underscores; start with a letter or underscore.

    Delete DATABASE_URL?

    Delete this personal application secret? Future use of this source will not include DATABASE_URL. Workloads depending on it may fail. Already-running processes may retain the value; this does not revoke access at an external service.
