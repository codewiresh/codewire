Provider credentials

A profile selects provider identities. Private keys and tokens stay outside the Sandbox behind a proxy, signer, or repository executor, except a personal Codex ChatGPT sign-in, which Codex receives inside the Sandbox. Existing Sandboxes keep their bound profile revision until updated; choosing no profile removes access on the next managed launch.
