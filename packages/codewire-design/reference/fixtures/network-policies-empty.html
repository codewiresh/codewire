Network policies

What your organization's Sandboxes may reach on the Internet. A policy allows names, wildcards or address ranges, each on its TCP ports.

Hosted Sandboxes don't enforce network policies yet, so a policy here changes nothing a Sandbox can reach.

Built in

  • open

    Every public destination on TCP 22, 80 and 443

    Used by 0
  • locked

    Nothing. A Sandbox's terminal, SSH and this dashboard keep working.

    Used by 0

No policies yet

By default, Sandboxes with no policy can reach any public address. Create a policy to lock them down further.

Or from a terminal: cw --cloud policy create NAME --allow docs.rs:443

3 Sandboxes select no policy and reach any public address on any TCP port. Policies on your own computer, for local VMs, stay in cw --local policy; the same name here and there is two policies.

Create a network policy

Lowercase letters, digits, dots and dashes.

A wildcard such as *.crates.io doesn't cover crates.io itself. Loopback, private, link-local and metadata addresses can't be allowed.
