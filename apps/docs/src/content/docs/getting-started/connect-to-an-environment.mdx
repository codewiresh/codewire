title: Connect to an environment
description: Open terminal, SSH, previews, and sessions
---

After your environment reaches **Running**, connect from the dashboard or CLI.

## Dashboard

1. Open the environment detail page.
2. Choose a terminal, file, SSH, or preview action.
3. Use the lifecycle and logs panels to inspect startup state if a connection is not ready.

## CLI

```bash
cw run -- claude "inspect this repo and summarize the test suite"
```

Use `cw env` commands to list and inspect environments from your terminal.

## Related

See [Connect to an environment](/docs/environments/connect) for the full connection reference.
