These tools reach Codewire environments through a plugin or through the SSH
hosts that [`cw setup ssh`](@/access/ssh-and-vscode.md) writes. Everything they
do, `cw` can do on its own; they put it where you already work.

| To | Use |
| --- | --- |
| run commands and attach to sessions from Rex's command palette | [Rex](@/integrations/rex.md) |
| run Orca workspaces in environments, or connect Orca to one | [Orca](@/integrations/orca.md) |
| open shells and agents in environments from herdr | [herdr](@/integrations/herdr.md) |
