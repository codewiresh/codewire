Codewire Mesh has been deployed!

1. Get the Mesh URL:
{{- if .Values.ingress.enabled }}
  Your Mesh endpoint is available at: {{ .Values.mesh.baseURL }}
{{- else }}
  kubectl port-forward svc/{{ include "codewire-mesh.fullname" . }}-http 8080:8080 -n {{ .Release.Namespace }}
  Mesh URL: http://localhost:8080
{{- end }}

2. Get the auth token:
{{- if eq .Values.mesh.authMode "token" }}
  kubectl get secret {{ include "codewire-mesh.fullname" . }} -n {{ .Release.Namespace }} -o jsonpath='{.data.auth-token}' | base64 -d
{{- else }}
  Auth mode is "{{ .Values.mesh.authMode }}" — no token required.
{{- end }}

3. Create or select a network:
  cw network create project-alpha --mesh-url {{ .Values.mesh.baseURL }} --token <auth-token>

4. Inspect environment-owned nodes in that network:
  cw network nodes --network project-alpha --mesh-url {{ .Values.mesh.baseURL }} --token <auth-token>
