Cloud sandboxes

Cloud environments for agents and their humans.

Persistent, isolated Linux environments you can access from anywhere, orchestrate through the CLI or SDK, and connect in encrypted private meshes.

Open one in the browser, SSH, or VS Code. Check out a public Git repository by URL, manage application secrets, and return to the same files, tools, and sessions.

Everything your session needs. Ready every time.

Enter a public repository URL, save your setup, and start a complete Linux sandbox for any session. Private platform repositories will use an explicit access profile and typed repository executor when that capability ships.

01

Choose a public repository

Use its Git URL directly. Codewire does not store or inject a raw forge token as a fallback.

$ git ls-remote https://github.com/acme/api
02

Set it up once

Save the image, tools, install commands, services, secrets, ports, and agent as a reusable preset.

$ cw init github.com/acme/api \
    --save-preset api
03

Add an app secret

Store application secrets in a project and bind it only where needed. Agent authentication stays separate.

$ cw secrets create api
$ cw secrets set api DATABASE_URL
04

Start a fresh sandbox every time

One click in the dashboard, or one command. The same complete sandbox is ready again—with its tools and credentials.

$ cw env create \
    github.com/acme/api \
    --preset api --secrets api --name auth
05

Connect over SSH or VS Code

Run this once. Then use OpenSSH, scp, rsync, or VS Code to connect to the same machine as the agent.

$ cw config-ssh
$ ssh cw-auth
06

Tell Codex what to build

Give the agent the outcome. It works inside the configured environment with the repository, tools, and app secrets already in place.

$ cw run --detach auth -- codex \
    "Build a Node.js web app that uses DATABASE_URL and runs on port 3000."
07

Start the server

Run the app as another persistent session. It stays live alongside the agent, even after you disconnect.

$ cw run --detach auth -- npm run dev \
    -- --host 0.0.0.0 --port 3000
08

Open a preview URL

Turn any running port into an authenticated URL for your team. No tunnel or manual proxy to keep alive.

$ cw env port add 3000 --label app \
    --access org_members --env auth
09

Come back when it’s ready

Reconnect to the same live session. Its files, process, and complete output are still there.

$ cw attach auth

Program it

Use the CLI, or use the SDKs for TypeScript, Python, and Go.

Create, start, stop, resize, and delete environments. Run commands. Read and write files. Open ports. Build Codewire into your own tools and products.

from codewire import Codewire

cw = Codewire()
env = cw.environments.create(
    name="api",
    repo_url="https://github.com/acme/api",
    image="workspace",
    wait=True,
)

result = env.exec(command=["pytest", "-q"])
port = env.create_port(port=3000, label="app")

The cw CLI supports hosted environments and native Linux environments backed by Cloud Hypervisor.

Choose your isolation level.

Use hypervisor isolation for everyday sessions. When source code, credentials, or customer data need stronger protection, use hardware-encrypted confidential isolation—and get a report that verifies it.
